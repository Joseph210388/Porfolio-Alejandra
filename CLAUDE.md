# Alejandra Rodríguez Portfolio

Personal portfolio web application showcasing profile, skills, experience, education, and contact.

## Tech Stack
- **Framework:** React 19.2.0
- **Build Tool:** Vite 6.2.0
- **Language:** TypeScript 5.8.2
- **Animations:** Framer Motion 11.3.11
- **Styling:** Custom CSS (no framework)

## Project Structure
```
src/
├── components/
│   ├── sections/ (About, Contact, Experience, Hero, Skills)
│   ├── ui/ (Carousel, Loading, Navigation, etc.)
│   └── icons/ (React icon components)
├── data/ (experience, skills, contact, education, etc.)
├── hooks/ (custom React hooks)
├── lib/ (animations, utilities)
└── types/ (TypeScript definitions)
```
